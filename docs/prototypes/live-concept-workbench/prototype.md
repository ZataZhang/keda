# 构想工作台：六种视觉方向

> **验证层级：设计概念（ImageGen 静态图片）**。本组图片用于评审构想工作台的布局和产物形态，不可点击，不连接模型或后端，不代表生产功能已实现。

## 目的

探索“想法还没成形时，用户与 Agent 对话，同时看到一个可讨论、可修订的产物”适合怎样呈现。六个方向沿用 KedaCode Console 的浅色界面与紫色强调色；示例内容“邻里工具共享”仅为便于理解画布的虚构示例。

## 候选方向

| 图 | 方向 | 主要收益 | 主要代价或风险 |
|---|---|---|---|
| 01 | 网页实时预览 | 结果直观，能快速判断方向是否接近预期 | 任意 HTML 预览需要隔离执行；可能让用户过早锁定界面 |
| 02 | 概念关系画布 | 显示想法的组成与相互关系，利于发现缺口 | 对视觉表达的呈现较弱 |
| 03 | 结构化概念说明 | 容易沉淀成 Idea Inbox 和 PRD 输入 | 视觉感染力相对有限 |
| 04 | 用户故事板 | 把场景和流程变得具体 | 连续插画可能替用户补出尚未确认的假设 |
| 05 | 多方向对比 | 用户能比较后选择，不必一次说清所有要求 | 同时生成多个方向会增加调用成本，单张卡片空间较小 |
| 06 | 多产物与修订轨迹 | 支持对话中切换产物并回看演进 | 标签和版本历史会增加首版界面复杂度 |

## 来源与限制

- 图片和完整提示词分别保存在 `assets/` 中；每张图片都有同名 `.prompt.md` 旁车。
- 六张图均由 OpenAI 内置 ImageGen 从文本提示生成，未使用参考图。所有图均为静态视觉草图，未验证页面交互、流式更新、会话保存、预览隔离、响应式行为或实际 `kc` 启动路径。
- 图片中的具体业务流程、产品文案、导航细节和数据均为示意，不能视作已确认需求或现有产品事实；导航是构图示意，没有逐项复刻当前 Console 侧栏。
