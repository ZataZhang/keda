先让目标电脑加入同一安全网络

目前没有互联网直连地址也没关系。请在要连接的电脑上安装 Tailscale，并使用和这台电脑相同的账号登录。

✦ Agent 会自动完成
  • 检查这台电脑的系统和 Tailscale 状态
  • 打开官方安装页，安装后自动检测连接
  • 发现新电脑并检查网络连通性
你需要在目标电脑完成
  1. 安装 Tailscale 并登录同一账号
  2. 按系统提示允许 VPN / 网络权限
  3. 如果启用了设备审批，在管理页面批准这台设备

选择 Agent 可以读取的文件夹

默认不开放任何个人文件。选择后，Agent 才能查看和引用其中的文档；文件始终只读。
