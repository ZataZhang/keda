关于 iar 管理终端

                

                  这是 iar 内置的 Agent Runner 管理终端（本机单用户模式，仅监听 127.0.0.1）。仓库队列、托管进程与 roadmap 数据均来自本机后端
                  API；runner 的行为由各仓库的 config.toml 与 .iar.toml 决定。退出后可通过命令行重新执行 iar console 打开。
