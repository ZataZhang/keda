                  API；runner 的行为由各仓库的 config.toml 与 .kedacode.toml 决定。退出后可通过命令行重新执行 kc console 打开。

执行器回退顺序 全局 · config.toml

                    
当前执行器失败或额度受限时，按顺序尝试下一位；本机未安装的执行器会跳过。每个候选可绑定同执行器的模型预设。回退链是全局 Runner 设置，不随上方生命周期范围切换。

                  

                  
                

                

                  

                  
同一执行器可以出现多次，每一行都是独立候选，可绑定不同的全局模型预设；相同的「执行器 + 预设」组合不能重复。回退配置固定写入全局 config.toml；修改预设请先切回全局范围并点“保存当前作用域”，再到这里绑定。
